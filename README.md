# Lets Box for Codex

Lets Boxの公式Codexプラグイン配布リポジトリです。

```bash
codex plugin marketplace add https://github.com/sorashiba11/letsbox-plugin
codex plugin add letsbox@letsbox
```

プラグインは認証済みRemote MCPへの接続情報だけを配布します。顧客のAPIキー、成果物、個別スキルフォルダはこのリポジトリへ含めません。

- Web: <https://app.letsai.team>
- MCP documentation: <https://mcp.letsai.team/docs>
- Privacy: <https://mcp.letsai.team/legal/privacy>
- Terms: <https://mcp.letsai.team/legal/terms>
