# LetsBox 認証情報の管理（EPSメール / SerpApiキー）

## 目的

「キーを変えたい」「いま何が登録されているか見たい」「キーを消したい」に直行で応えるスキルです。

## ルール

- 使ってよいのは、プラグインが登録済みのMCPサーバー「letsbox」のツールだけです。
- `https://mcp.letsai.team` への直接アクセス、MCPサーバーの新規登録・設定変更、OAuth認証の代行は禁止します。
- 受け取ったキーは `set_runtime_credentials` に渡す以外の場所（ファイル・ログ・要約・報告文）に書き残さないでください。報告に含めてよいのは登録済みメールアドレスとキーの下4桁だけです。
- ここで扱うのはeBayスキル用の実行キーです。LetsBoxのログイン（アカウント）とは別物なので、混同した案内をしないでください。ログインの話なら letsbox-connection-check / letsbox-switch-account を使います。

## 手順

1. `get_runtime_credentials_status` を呼ぶ。
2. 依頼内容ごとに:
   - **確認**: 登録済みなら「EPSメール ○○、SerpApiキーは下4桁 ××××、最終更新 △△」と伝える。未登録なら「まだ登録されていません。登録しますか？」と聞く。
   - **差し替え（ローテーション）**: 「新しいEPSメールとSerpApiキーを教えてください（片方だけ変える場合も両方の値が必要です）」と案内し、受け取ったら `set_runtime_credentials` を1回呼ぶ（上書き登録になる）。
   - **削除**: 影響を一言添えて確認を取る（「削除すると、次のeBayスキル実行時に再登録が必要になります」）。OKなら `clear_runtime_credentials` を呼ぶ。
3. 操作後は必ず `get_runtime_credentials_status` を呼び直し、結果（`source: tenant_store` / `none`）を確認して報告する。
4. 補足として「実行中の作業は開始時のキーで最後まで動き、新しいキーは次の実行から使われます」と伝える。

## 注意

- 認証情報はアカウント（メンバー）ごとに別管理。切り替えたアカウントで未登録なら、このスキルで新規登録すればよい。
