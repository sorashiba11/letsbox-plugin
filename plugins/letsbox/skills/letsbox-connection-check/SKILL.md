# LetsBox 接続・アカウント診断

## 目的

「どのアカウントで繋がっているの？」「認証エラーが出た」「ツールが動かない」——そんなときに、接続状態を確認して、必要な対処だけを分かりやすく案内するスキルです。

## ルール

- 使ってよいのは、プラグインが登録済みのMCPサーバー「letsbox」のツールだけです。
- `https://mcp.letsai.team` へ curl / fetch 等で直接アクセスすること、MCPサーバーを新規登録・設定変更すること、OAuth認証を代行することは禁止します。
- 利用者への説明では専門用語（OAuth・スコープ・issuer・テナント等）を避け、やさしい言葉に言い換えてください。

## 手順

1. ツール一覧にMCPサーバー「letsbox」のツールが見えるか確認する。
   - 見えない場合は接続を一切試みず、「Codexを再起動して、新しいスレッドでもう一度お試しください」とだけ案内して終了する。
2. `get_connection_status` を呼ぶ。
3. 応答の `guidance` を、利用者にそのまま伝わる言葉で報告する。最低限、次を含めること:
   - いまログインしているアカウント（`account_email` と会社名）
   - 使える機能の状態（権限が足りているか、eBay用の認証情報が登録済みか）
   - 問題がある場合は、その直し方（guidanceに書かれた手順をそのまま案内）
4. 401や認証エラーでツール自体が失敗する場合は、自分で対処せず次を案内して終了する:
   - 「ターミナルで `codex mcp logout letsbox` → `codex mcp login letsbox` を実行してください。ブラウザが一瞬開いて自動で完了します」
   - ログインが issuer エラーで失敗する場合:「`npm install -g @openai/codex@latest` でCodexを更新してから、もう一度お試しください」
5. 別のアカウントに切り替えたい場合:「`codex mcp logout letsbox` → `codex mcp login letsbox` を実行し、開いたブラウザで目的のアカウントでログインし直してください」と案内する。

## 報告の例

「現在 ○○@example.com（△△株式会社）のアカウントで接続しています。権限・認証情報ともに正常で、このままリサーチなどのスキルを実行できます。」
